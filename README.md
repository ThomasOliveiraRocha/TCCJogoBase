# Jogo Educativo para o TCC

Projeto desenvolvido como base para o Trabalho de Conclusão de Curso (TCC), com foco na criação de um jogo digital em HTML5, CSS3 e JavaScript puro. A estrutura foi pensada para facilitar a organização do código e permitir futuras expansões e melhorias.

## Acesse o Jogo

Você pode testar o jogo diretamente pelo GitHub Pages no link abaixo:

 **https://thomasoliveirarocha.github.io/TCCJogoBase/**
